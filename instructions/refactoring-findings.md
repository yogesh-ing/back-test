# Refactoring Findings Tracker

Collects every missing point, deferred decision, edge case and follow-up
surfaced by the refactoring tickets (P1.1 → …) so they can be addressed
collectively later instead of being lost between tasks.

## Pitfalls (known traps, for future tasks)

| ID | Pitfall | Notes |
|---|---|---|
| K-01 | Sizing entries off `current_cash` collapses when a close is still in flight (cash ≈ 0, equity = full value) | Any all-in sizer must size off `calculate_total_equity()`, not cash (this cost one debug round in P1.5; `_funded_all_in` in the equivalency test is the reference) |
| K-02 | The simulator `Order` class and the ledger `Order` dataclass share a name | In `paper_runner.py` the simulator one is imported as `SimOrder`; keep it that way |
| K-03 | `executor.execute()` raising `InsufficientFundsError` on an unfunded fill is a **tested contract** (`test_simulator_execution.py::test_portfolio_limits_still_apply`) | Don't soften it in the simulator; handle it at the runner level (haircut sizing + caught backstop) |
| K-04 | Gapless-data precondition: prev-close (backtester) == next-open (paper runner) only when `open[t] == close[t-1]` | Any equivalency test on real (gapped) data must state the fill-anchor difference explicitly |
| K-05 | Sandbox resets wipe `~/.venv` repeatedly | Rebuild: `python3 -m venv ~/.venv && ~/.venv/bin/pip install -q -r requirements.txt`; run tests with `PYTHONPATH=src` |
